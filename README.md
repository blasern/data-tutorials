# Tutorials (4 weeks × 3 notebooks)

Each notebook is meant to be done after the week's videos.

* Requirements: Python 3 with `numpy`, `pandas`, `matplotlib`, `scipy`, `scikit-learn`.
* All data is **simulated** and is read directly from https://github.com/blasern/data-tutorials/ (variable `DATA_URL` in the first code cell of each notebook; the local copy in `data/` is the source to upload there). An internet connection is needed.
* Do the **✏️ Your turn** blocks in order; later cells reuse your results. The quiz asks for the numbers they produce.
